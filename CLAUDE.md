# Jellio Tizen

Samsung Tizen OS TV client for Jellio: a native lookalike, backed entirely by a
Jellio-Plugin server (Jellyfin + Gelato) over its own real REST API. No local
media, no bundled catalog addon runtime; this app is a thin, directly
rendered TV client over a server that already does every real catalog
aggregation, search, and stream resolution job itself.

## Relationship to Jellio-Plugin and Jellio-TV

`NoahSKipp/Jellio-Plugin` is this app's own real backend: its `Controllers/`
already expose everything a client needs (System Info, Views, Items, Images,
Favorites/Watchlist, playback URLs, the Calendar, Group Watch chat) over
plain Jellyfin-compatible REST.

`NoahSKipp/Jellio-TV` is this app's direct sister client for Android TV.
Jellio-Tizen mirrors Jellio-TV 1:1 in UI, behavior, spatial navigation, and
feature parity, targeting Samsung Smart TVs running Tizen OS 4.0+.

## Working rules

Same hard rules as `NoahSKipp/Jellio-Plugin` and `NoahSKipp/Jellio-TV`, unchanged:

### Authorship

- Every commit is authored and committed by `NoahSKipp <kippnoahsamuel@gmail.com>`.
- No `Co-Authored-By` trailers. Ever.
- No "generated by", "made by", "with help from" or any similar attribution
  in commit messages, PR bodies, code comments, docs, config files or
  release notes.
- Nothing anywhere in this repository names an AI assistant as a
  contributor.

### Branches

- Branch names describe the feature being worked on.
- Never include the word `claude`.
- Never include digits.
- Lowercase, hyphen separated.

### Commits

- Conventional commit prefixes (`feat:`, `fix:`, `refactor:`, `chore:`,
  `docs:`, `ci:`, `style:`, `test:`).
- One logical change per commit. No mega commits.
- Push with `git push -u origin <branch>`.

### Code style

- Comments are sparse. Only for genuinely non obvious blocks, written as a
  short note to self, not documentation prose.
- No banner comments, no section dividers, no restating what the line does.

### Writing

- No em dashes anywhere. Not in code, comments, docs, commit messages,
  config, UI strings or release notes.

## Architecture

```
Jellio-Tizen/
  config.xml           Tizen W3C widget configuration
  index.html           1080p TV shell hosting players, canvas, overlays, roots
  package.json         ES module test scripts
  css/
    base.css           Design tokens, focus rings, overscan, safe areas, animations
    nav.css            SidebarNav, HomeClock, QuickHub drawer, AccountSwitcher
    components.css     PosterCard, CardDialog, CardOptionsMenuRow, Toasts
    screens.css        Login, Home, Detail, Person, Library, Search, Feed, LiveTv, Settings
    player.css         Fullscreen player, scrubber, controls, drawers, overlays
  src/
    main.js            Entry point initializing platform, input, spatial nav, app state
    input/
      remote.js        Samsung Tizen remote keys registration, normalization, long-press
      spatialNav.js    Deterministic 10-foot 2D spatial navigation engine
```
